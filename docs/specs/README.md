# CUDA-NN specifications

**No production component or API specification is accepted yet.**

The [inference justification assessment](https://github.com/iteathen/cuda-nn/issues/2) first determines whether a reusable NN layer adds value beyond direct Tensor composition. Retained capabilities then require accepted contracts and appropriate qualification under [AGENTS.md](../../AGENTS.md).

The [architecture decisions](../decisions/README.md) establish ownership and optional RNG/communication composition. Roadmap issues organize work and do not authorize implementation. Historical CUDA-JS SPEC-0027 does not govern this repository.
